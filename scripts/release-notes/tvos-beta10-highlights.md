## Highlights

- **Pinned Nuvio-Style Hero** — the headline of this beta, and the layout u/mrStevenx3 has been asking for since the "Lucky" screenshot: with **Nuvio-Style Hero** on (Settings → Home Screen), the hero no longer scrolls away. It stays pinned at the top of Home — title, description and artwork updating **live with whichever title you focus** — while only the rows scroll beneath it, no matter how deep you browse. The pinned layout is a compact hero (2-line synopsis) so a full poster row always fits below it. Tuned across eight rounds on real hardware so titles, posters and captions rest cleanly at every scroll position.
- **See All is now a card in the row** — the full-catalog link moved from the row header into the shelf itself, as a tile at the end of each row (Home and Search). Vertical navigation only ever lands on cards now, which also fixed several odd scroll rest positions.
- **Focus-follows-backdrop hero (UX-7)** — as shipped in the previous betas' commitment: the hero backdrop and info follow the focused poster in real time, in both classic and Nuvio-style layouts.
- **Trailer thumbnails on the detail page (UX-10)** — the Trailers & Extras row shows 16:9 YouTube thumbnails.
- Plus the full beta.10 fix batch: Search Sources works (BUG-33), actor pages no longer trap scrolling (BUG-34), depth-effect and collection-corner fixes (BUG-31/32), profile picker default-focus (UX-11), aspect-filled focus trailers (UX-9), the opt-in accent focus ring (FEAT-14), GIF-row performance work (BUG-19), and 1080p trailers via the new local HLS repack (UX-4c).
