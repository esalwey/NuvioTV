## Highlights

- **Tiếng Việt / Vietnamese** — the whole UI is now available in Vietnamese (Apple TV language → Tiếng Việt), and "Vietnamese" joins the metadata, audio and subtitle language lists. The other four languages caught up on every string added since beta.9 at the same time.
- **Pinned hero: row titles no longer collide with the artwork** — in Nuvio-Style Hero (pinned) mode the focused card's lift used to clip or cover the row title on the leftmost cards, and the title jumped between rows. Rows now sit 16 pt airier so the lift clears the title, and the title glides instead of snapping.
- **Search → See All shows what you searched for** — expanding a search row's See All returned the addon's unfiltered catalog (or an empty grid for search-only catalogs like Stremio Catalog Plus). The query now travels with the request, so See All is the actual result set. Collection folder grids also **remember your position** when you back out of a title.
- **No Zoom on Focus reaches every tile** — the toggle only covered poster/landscape cards; See All cards, episode cards and the detail-page trailer thumbnail still zoomed. All of them now honor it.
- **Sharper collection GIFs on 4K** — animated collection tiles were decoding at ~200 px on a ~780 px tile. They now decode at HD parity or better (aspect-aware, with a larger 4K budget) and trade a few frames rather than resolution — device-verified sharper without choppy playback.
- **Trailer pipeline is stateless** — the "trailers stop playing until I reinstall" report: extraction traffic no longer keeps YouTube identity cookies or a disk cache between launches, so a rate-limited identity can't survive a restart. A 15-minute device soak on this build stayed alive throughout; if it dies for you anyway, the new `[TrailerPipeline]` diagnostics name exactly where.
- **White theme: Settings sidebar label is back** — the focused sidebar row rendered white-on-white on the White theme; it now draws a dark label deterministically. Stream-list language badges also render their pack colors exactly as the phone does (8-digit hex was parsed as RGBA instead of ARGB).
- **Metadata Language = Français fixes** — the hero commits once, already localized (no English→French swap on launch), and rows localize their captions as they scroll into view.
- **Collections** — a collection's configured backdrop artwork now renders on its folder tile (it was synced but never drawn); GIF tiles decode at tile size.
- **VidHub in the player list (known issue)** — VidHub now appears in Settings → Playback → Default Player and the stream long-press menu, implemented per VidHub's own x-callback-url docs and verified byte-exact on device — but VidHub's current tvOS build ignores the handoff and opens to its home screen. Reported to Oka Apps; it will start working when they ship the fix, no update needed here.
- Plus, ported from Nuvio mobile: watched-state storage compaction (fixes an out-of-memory on very large libraries), faster Trakt watched-sync, a Simkl "completed series" reconciliation fix, addon cache-control honored on manual refresh, and the autoplay-fallback setting (functional via settings sync from mobile). The UI test suite is up to 57 tests plus 14 GIF-planner tests.
